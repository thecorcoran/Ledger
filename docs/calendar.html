Feed Standards & Inclusions

What is included: Feeds include only briefed matters, scheduled public hearings, and documented written comment deadlines. Routine procedural agenda lines are filtered out so your calendar remains uncluttered.

Deadline Reminders: Comment deadline entries feature an automatic 1-day advance notification reminder (VALARM).

Stable Event IDs: Each policy matter has a permanent UID. If a meeting time changes or a matter is postponed, your calendar app updates the existing event rather than creating a duplicate.

Strict Verification: All dates and deadlines are taken strictly from published agenda packets and hearing notices. If a deadline is not documented, we do not guess; please confirm on the official agenda.

How to Subscribe

Apple Calendar (Mac / iOS)

Click the "Subscribe in Calendar" button above or open Calendar → File → New Calendar Subscription and paste the calendar address.

Google Calendar

Click "Copy Link for Google Calendar" above, then open Google Calendar on the web → Other calendars (+) → From URL, and paste the link.

Microsoft Outlook

In Outlook Calendar, select Add Calendar → Subscribe from web, paste the link, and choose your preferred refresh interval.
